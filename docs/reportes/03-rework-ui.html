De "un ASP clásico de 2005" a una consola de estudio de producción · antes/después por pantalla · Opus implementó, Fable especificó · 2026-07-10

0 Qué se hizo, de un vistazo

El rework funcional (docs/07) definió comportamiento y datos pero nunca una dirección visual, y ningún gate obligaba a mirar la pantalla. Este rework cierra ese hueco: solo presentación (CSS, estructura JSX, iconos, micro-interacciones) — cero lógica, cero endpoints, los 174 tests intactos.

La vara — "consola de estudio de producción": referencia mental DaVinci Resolve / Frame.io / Linear. Dark cinematográfico con profundidad REAL por capas (fondo → panel → tarjeta → activo), dorado = identidad/creativo (escaso, vale porque no se repite), acentos por semántica fija (azul = IA · verde = aprobado · ámbar = hook · violeta = remate · rojo = error), tipografía con carácter (serif display para títulos y números grandes).
