Pack Flow al flujo NUEVO de Google Flow (imagen-first)

Google Flow pasó a modelar Personajes (entidad con IMAGEN de referencia) y Escenas. El Pack Flow deja de dar un master monolítico de texto y produce estilo + personajes + escenas. Fable especificó, Opus implementó · 2026-07-11

0 Qué se hizo, de un vistazo

Lucas mostró con la UI de Flow en mano: "el master monolítico de texto me generó 4 imágenes estáticas — Flow lo tomó como prompt de imagen". Flow ahora es imagen-first: se crea un Personaje, se le genera una imagen de referencia (Nano Banana) y las Escenas se animan llamando al personaje por su NOMBRE — la imagen fija la cara, no el texto. Repetir el fisicoEn verbatim en cada prompt (nuestra "garantía") era justo lo que rompía Flow. El molde flowpack se reescribió a las 3 piezas del flujo nuevo.
